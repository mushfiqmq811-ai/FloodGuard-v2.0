FloodGuard BD — GloFAS Core Repair

This build fixes the upstream forecast parsing path and removes the misleading
"50% signal" placeholder behavior.

Data rules:
- Copernicus CEMS / GloFAS operational forecast is the only hydrological source.
- No synthetic hydrological fallback.
- Control forecast powers the public 20-zone dashboard.
- Research Mode requests a small selected-zone ensemble.
- A forecast is accepted only when at least 3 valid lead days are parsed; normal
  public operation expects all 15 requested lead days.
- Relative forecast-window position is NOT a flood probability.
- Missing authentic data is shown as unavailable rather than invented.

Research:
- Historical target uses current GloFAS historical v5.0 API structure.
- Verification is GloFAS forecast vs GloFAS modelled historical discharge,
  not independent Bangladesh gauge validation.

Debug:
- GET /api/glofas/diagnostics reports station count and parsed forecast lengths
  without exposing API credentials.
