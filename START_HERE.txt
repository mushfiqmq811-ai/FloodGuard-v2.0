FLOODGUARD BD — OFFLINE DATA BUILD

1. Put Gemini's processed file at data/glofas_processed.csv.
2. Check data/DATA_QUALITY_REPORT.md and data/glofas_manifest.json.
3. Install runtime deps: pip install -r requirements.txt
4. Optional model training: pip install -r requirements-train.txt
5. Train: python scripts/train_model.py
6. Run: python app.py

No GloFAS API key is needed by the website.
No raw NetCDF/GRIB files are required at runtime.
See GEMINI_DATA_PROCESSING_PROMPT.md for the exact processing prompt.
