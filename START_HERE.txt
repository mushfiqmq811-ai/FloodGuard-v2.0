FLOODGUARD BD — GLOFAS-ONLY

1. Set CDS_API_KEY on Render.
2. Deploy with the Build/Start commands in DEPLOY_RENDER.txt.
3. Open the dashboard.
4. FloodGuard requests one regional GloFAS operational forecast and maps it to the 20 configured zones.
5. Open Research to inspect the source, coverage and ensemble forecast evidence.

There is no synthetic fallback. If EWDS/GloFAS is unavailable, the affected dashboard state is explicitly DATA UNAVAILABLE.
