How FloodGuard BD works

Simple on the surface, detailed underneath.

📡

1. Collect

Copernicus GloFAS provides the operational river-discharge forecast used by FloodGuard.

🧹

2. Process

Forecast discharge, ensemble spread and transparent decision-layer signals are organized for analysis.

🤖

3. Predict

GloFAS provides an operational 15-day river-discharge forecast and FloodGuard derives a relative forecast signal from it.

🗣️

4. Explain

The interface converts complex signals into understandable summaries, maps and forecasts.

Responsible data labels

GloFAS forecastAuthentic Copernicus river-discharge forecast in m³/s.
Relative signalFloodGuard compares each zone’s forecast values within its own 15-day forecast window.
ImportantThe relative forecast signal is not an official flood-warning threshold and must not replace local authority guidance.
